# Kayans — Moroccan Heritage Wear (E-Commerce Storefront)

A modern, responsive e-commerce web application built with **React 19**, **TypeScript**, and **Vite 6**, showcasing Moroccan heritage fashion collections with hash-based multi-page navigation, dynamic category filtering, and interactive UI components.

## Key Features

- **Multi-Page Storefront:** Dedicated views for Home, Shop All, New Arrivals, Collections, Men, Women, About Us, Contact Us, Track Order, My Account, and Settings.
- **Dynamic Product Filtering:** Filter catalog items seamlessly across product categories.
- **Reusable Component Architecture:** Modular TypeScript components (`Header`, `SideMenu`, `HeroSection`, `FeaturedProductsSection`, `SpecialCollectionSection`, `ProductCard`, `Button`, `Icons`).
- **Fast Dev & Build Tooling:** Powered by Vite 6 and strict TypeScript typing.

## Tech Stack

- **Frontend:** React 19, TypeScript, HTML5/CSS3
- **Build Tool:** Vite 6

## Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
